Token launch radar: 198 pre-token protocols ranked by expected launch value — what the token would be worth, times the chance it ever launches — with launch odds, honest 80% intervals and costed farm plans, built from the DefiLlama snapshot. Model radar-4: fitted category multiples (leave-one-out median error 1.58, vs 1.69 for v1), launch odds from the peers' record, every term kept or dropped on held-out data.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
