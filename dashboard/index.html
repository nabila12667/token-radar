How the value is scored

expected = TVL × fitted multiple × launch odds

Fitted multipleThe median log(market-cap / TVL) of the snapshot's live-token protocols in the same category, shrunk toward the global median with weight n / (n + 3). No clamp: the shrinkage, not a hard bound, keeps a thin category honest.
Launch oddsThe category's launch rate — live-token protocols over all protocols in the category, smoothed toward the global 55% — times an age decay: full odds for the first year with no token, halved every ~2 years after. Lending launches 78% of the time; Risk Curators 15%.
Honest intervalEvery row carries an 80% interval from the leave-one-out errors: four in five live tokens are priced within 14×, half within 4.8×. The point value is a claim, not a precision — the interval is the honest part.
Farm verdictEach plan is costed: capital, gas, active hours, and the expected value per wallet in $/hour, assuming 5% of the launch value goes to farmers split among 10,000 farmers. Worth, marginal, or skip — with the arithmetic shown.

Nothing here names a protocol: the same formula scores every row. “Records no token” means DefiLlama's record carries no token — it is not proof the protocol has none. An expected value is this entry's own claim, never make.fun's, and it does not predict whether or when a token is issued.
