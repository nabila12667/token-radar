How the value is scored

implied = TVL × category multiple × growth × maturity × breadth

Category multipleThe median market-cap / TVL of the snapshot's live-token protocols in the same category (3 or more of them), else the median over all live-token protocols. A lending token is priced like lending tokens trade, not like dex tokens do. Clamped to 0.05–1.50.
Growth1 + clamped 7-day TVL change (−50%…+100%) × 0.6. Growing TVL is worth more; one wild week cannot own the board.
Maturity0.65 + 0.35 × ln(1 + age) / ln(1096), age in days since first listed, capped at 3 years. Longer with no token, more record a launch would price — with diminishing returns. Unknown age counts as 365 days.
Breadth1 + 0.03 per chain, up to 5 chains. More chains, more distribution — a small boost on purpose.

Nothing here names a protocol: the same formula scores every row. “Records no token” means DefiLlama's record carries no token — it is not proof the protocol has none. An implied value is this entry's own claim, never make.fun's, and it does not predict whether or when a token is issued.
